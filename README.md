# Coffee Shop Website

A responsive, accessible, and SEO-optimized single-page coffee shop website built with plain HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Accessibility**: WCAG 2.1 AA compliant with ARIA labels, proper contrast, and keyboard navigation
- **SEO Optimized**: Includes meta tags, structured data (JSON-LD), and semantic HTML
- **Modern UI**: Clean, attractive design with smooth animations and hover effects
- **Functional Components**:
  - Menu section with coffee drinks and pastries
  - Business hours display
  - Location with embedded map
  - Contact form with client-side validation
  - Mobile-friendly navigation menu
