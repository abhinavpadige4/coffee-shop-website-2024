# Coffee Shop Website

A responsive, accessible, and SEO-optimized single-page coffee shop website built with plain HTML, CSS, and JavaScript.

## 🌟 Live Demo
**Deployed on Vercel**: https://coffee-shop-website-2024.vercel.app

## 📋 Overview
This is a complete, production-ready coffee shop website featuring:
- Elegant design with coffee-themed color palette
- Full menu with prices (espresso, latte, pastries, etc.)
- Business hours display
- Location with embedded Google Map
- Contact form with validation
- Fully responsive layout
- Accessibility compliance (WCAG 2.1 AA)
- SEO optimization

## 🛠️ Technologies Used
- HTML5 (Semantic Elements)
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (ES6+)
- Google Maps Embed API

## 🎯 Features Implemented
✅ Single-page static site
✅ Menu section: espresso, latte, cappuccino, americano, mocha, croissant, muffin, scone with prices
✅ Business hours section (weekday vs weekend)
✅ Location section with embedded map and contact info
✅ Contact form with client-side validation
✅ Responsive design (mobile, tablet, desktop)
✅ Accessibility compliance (WCAG 2.1 AA)
✅ SEO basics (meta tags, structured data, semantic HTML)
✅ Plain HTML+CSS+JS, no frameworks
✅ Mobile navigation toggle
✅ Smooth scrolling for anchor links
✅ Form validation with real-time feedback
✅ Skip navigation link for accessibility
✅ Proper color contrast ratios
✅ Keyboard navigable interface

## 📱 Responsive Breakpoints
- **Mobile**: < 480px - Single column layout, hamburger menu
- **Tablet**: 480px - 768px - Optimized spacing, beginning of multi-column layouts
- **Desktop**: > 768px - Full multi-column layouts
- **Large Desktop**: > 1024px - Maximum content width with generous white space

## 🎨 Design System
**Color Palette**:
- Primary: #8B4513 (SaddleBrown) - Rich coffee brown
- Secondary: #D2B48C (Tan) - Light coffee/cream
- Accent: #CD853F (Peru) - Coffee with milk
- Background: #F5F5DC (Beige) - Light neutral tones
- Text: #2F1B0C (Dark coffee) - Dark brown for readability

**Typography**:
- Headings: Georgia, serif (elegant, readable)
- Body: Georgia, serif with fallback to sans-serif
- Clear typographic hierarchy for readability
