## Manual Deployment Instructions
To deploy this site manually:

### Vercel
1. Go to vercel.com
2. Click "New Project"
3. Import the GitHub repository: `abhinavpadige4/coffee-shop-website-2024`
4. Vercel should automatically detect it's a static site and deploy it

### Netlify
1. Go to netlify.com
2. Click "New site from Git"
3. Connect your GitHub repository
4. Set build command to: `npm run build` (or leave blank for static site)
5. Set publish directory to: `/` (root)

### GitHub Pages
1. Go to repository Settings
2. Click "Pages" in the left sidebar
3. Under "Source", select the `main` branch
4. Choose `/ (root)` as the folder
5. Click Save
